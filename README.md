# Bahya Nireekshana

Network monitoring, part of [Brahma](https://github.com/sudharamachandranrajeev/brahma).
*Bāhya nirīkṣaṇa* is Sanskrit for "watching what goes out".

- [`omarchy/`](omarchy/README.md): the Omarchy bar widget and the OpenSnitch / vnstat / nethogs setup (formerly *netwatch*).

The cross-platform app (Linux, Windows, Android) and the browser extension are being built.
